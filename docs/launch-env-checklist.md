# Launch Environment Checklist

Set these variables before launch smoke checks and production rollout.

Template source:

- `.env.launch.template`

## Required
- DATABASE_URL
- NEXTAUTH_URL
- NEXTAUTH_SECRET
- STRIPE_SECRET_KEY
- NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY
- STRIPE_WEBHOOK_SECRET
- OPS_CRON_SECRET
- OPS_ALERT_WEBHOOK_URL

## Strongly Recommended
- OPS_ALERT_WEBHOOK_BEARER_TOKEN
- OPS_ALERT_PAYMENT_FAILURE_RATE_WARN
- OPS_ALERT_PAYMENT_FAILURE_RATE_CRITICAL
- OPS_ALERT_WEBHOOK_FAILED_WARN
- OPS_ALERT_WEBHOOK_FAILED_CRITICAL
- OPS_ALERT_WEBHOOK_STALE_WARN
- OPS_ALERT_WEBHOOK_STALE_CRITICAL
- OPS_ALERT_STALE_PENDING_ORDERS_WARN
- OPS_ALERT_STALE_PENDING_ORDERS_CRITICAL
- OPS_ALERT_PENDING_PAYOUT_COUNT_WARN
- OPS_ALERT_PENDING_PAYOUT_COUNT_CRITICAL
- OPS_ALERT_PENDING_PAYOUT_TOTAL_WARN_CENTS
- OPS_ALERT_PENDING_PAYOUT_TOTAL_CRITICAL_CENTS
- OPS_ALERT_PENDING_WITHOUT_CONNECT_WARN
- OPS_ALERT_PENDING_WITHOUT_CONNECT_CRITICAL

## Scheduler Setup
- Endpoint: /api/internal/ops/daily-reconciliation
- Method: POST
- Header: x-ops-secret = OPS_CRON_SECRET
- Cadence: daily
